# 不分仓拼箱（pinxiang_bot）

物流机器人菜单 **3. 不分仓拼箱**。

## 流程

1. **物流**上传发货单 → 机器人回拼箱结果（仅改箱行）  
2. 物流回复 **确认** → 选择运营：  
   - `1` 袁皓冉  
   - `2` 陈潇潇  
3. 机器人把拼箱结果 **私聊转发给所选运营**  
4. **运营**上传亚马逊「包装箱包装信息」Excel  
5. 机器人填写后回传运营，并抄送物流  

**不会**填写 `ManifestFileUpload_…MPL2.xlsx`（创建货件 Manifest）。

## 同步文件

统一目录见仓库根 `files/README.md`（产品信息单证专用等）。
