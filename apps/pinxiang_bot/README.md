## 流程（摘要）

1. **物流**上传发货单 → 机器人回拼箱结果（仅改箱行；文件名如 `SP… SP… 拼箱数据.xlsx`），并按 `templates/` 生成 Amazon Manifest 模板1  
2. 物流 **确认** → 选择运营（序号/姓名）；运营同时只接 1 单，忙则请改选  
3. 机器人将**拼箱结果 + Amazon 模板1**私聊转发给运营（文案含物流渠道/店铺/国家）  
4. 运营可回复 **【模板2】** 换 MPL2 格式；也可上传卖家后台「包装箱包装信息」表  
5. 若上传装箱表：机器人填写后回传运营（**文件名与上传一致**）；物流仅收「已完成」文本通知  

模板源：`apps/pinxiang_bot/templates/`（与 `dingtalk-lcl-bot/Template_Files` 同款）。

## 拼箱规则（摘要）

- 单箱毛重目标 **1～18 kg**；非原箱尺寸单边 **15～60 cm**；体积 &lt;10000 → 20×20×20  
- 整箱不改、不进结果表  
- 不足一箱：够重单装；&lt;1kg 可同仓合箱  
- 超过 1 箱有零头：**先**试整票拼 1 箱（1～18kg）；不行再拆「整箱 + 零头」；零头 &lt;1kg 可借箱  
- 完整说明见 [docs/业务与流程逻辑.md](docs/业务与流程逻辑.md)
